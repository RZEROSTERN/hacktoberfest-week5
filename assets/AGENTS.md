# Asset rules

- Write docs/ART_STYLE.md first and follow it for every image: one consistent
  Mexican folk-art illustration style, warm candlelight against night colors.
- Log every generation prompt, target filename and size in docs/ART_PROMPTS.md.
- Use built-in image generation through the development subscription; never call an
  image API or add a key. If unavailable, stop and prepare prompts for assets/incoming/.
- No film/game/brand references or imitation, copied protected artwork, real people's
  likenesses, or text inside images. Public-domain Posada engravings may guide the style.
- Optimize shipped art to WebP; total art stays below 30 MB. Generate flicker, smoke,
  petals and translucency in code. Preserve original inputs locally for reproducibility.
- Audio must be procedural or permissively licensed; fonts must be open licensed.
- Record every external asset source/license in CREDITS.md and include license files.
- Treat the ofrenda and the dead with dignity. No monster or costume framing.
